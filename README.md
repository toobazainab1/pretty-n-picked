# Pretty N Picked
Static site (HTML/CSS/JS). Run with VS Code Live Server or `npx serve`.
Deploy: push to GitHub and import on Vercel, or `npx vercel` (Framework: Other, no build command).

## Before going live (SEO)
Replace `https://www.prettynpicked.com` with your real domain in `index.html`, `robots.txt` and `sitemap.xml`, and update the Instagram link in the JSON-LD.
Submit sitemap.xml in Google Search Console.
